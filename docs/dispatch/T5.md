## 6. 实现要点

1. **SPEC 3.3.3 里那句 `jest.mock('../../api/index')` 是从页面文件视角写的,照抄进 `tests/pages/*.test.js` 会报 `Cannot find module`(已实测)。** 测试文件里正确写法是:
   ```js
   jest.mock('../../miniprogram/api/index');
   const api = require('../../miniprogram/api/index');
   ```
   三个测试文件都在 `tests/pages/` 下,mock 路径统一是这一个。
2. **你的页面文件里 require api 的相对路径和别人不一样。** `pages/dog/edit/edit.js` 和 `pages/dog/profile/profile.js` 比其他页面深一层,要写 `require('../../../api/index')`(T0 留的占位注释已经是这个);`pages/me/me.js` 才是 `require('../../api/index')`。
3. 页面模块必须按 3.3.4 收尾:`Page(options); module.exports = options;`。**少了 `module.exports`,`loadPage()` 就拿不到页面对象**,你的测试会直接跑不起来。
4. **游客态是 B7 的核心**:`api.getDogPublic` 成功但用户未登录时,页面要正常渲染、`data.dog` 有值、**不跳转登录**。断言后半句的办法是查 `page.__wx.__calls` 里没有 `navigateTo` / `redirectTo` / `reLaunch`。
5. 名字 12 字符上限来自 3.2 的 `name: String, // 1-12 字符`。超长要在**页面本地**拦下,**不调 api**(6 节 T5) —— 用 `expect(api.saveDog).not.toHaveBeenCalled()` 断言后半句,这半句最容易漏。
6. 捕获 `ApiError` → 设 `data.errMsg`,**不得抛出、不得白屏**(3.4)。页面里不许出现 `new Date()`(3.3.4)。
