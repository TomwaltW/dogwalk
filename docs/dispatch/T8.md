## 6. 实现要点

1. **页面骨架**照 3.3.4:`const options = {...}; Page(options); module.exports = options;`;`wx` 一律 `host.wxOf(this)`;回调式 API 用 `host.promisify(w, 'getLocation')({ type: 'gcj02', isHighAccuracy: true })`;页面里不许 `new Date()` / `Math.random()`。占位页里那两行 `void api; void host;` 删掉。每页 WXML 末尾保留 `<privacy-popup id="privacy-popup" />`。
2. **首页地图 `pages/index`:**
   - `data`:`parks`(ParkSummary[])、`markers`、`center`(缺省 `config.DEFAULT_MAP_CENTER`)、`scale`(`config.DEFAULT_MAP_SCALE`)、`loading`、`errMsg`、`seeded:false`。
   - `onLoad` / `onShow` / `onPullDownRefresh` 都走 `loadParks()`:`api.listParks()`;返回 `[]` 且 `!seeded` → `api.initParks()` 一次(置 `seeded:true`)再 `listParks()`;有公园时 `center` 取第一个公园。api 抛错 → `errMsg`,不抛。
   - `markers` 每项:`{ id: <数字下标>, parkId, latitude, longitude, title: name, iconPath: '/pages/index/marker.png', width: 28, height: 28, callout: { content: name + ' · ' + activeDogCount + ' 只狗', display: 'ALWAYS', padding: 8, borderRadius: 8, fontSize: 12 } }`。`marker.png` 已经在你目录里(T0' 放的 48x48 橘色圆点;想换就换,`scripts/make-marker.js` 能再生成)。`<map>` 的 marker **必须有 `iconPath`**,漏了真机不显示。
   - WXML:`<map id="map" class="map" markers="{{markers}}" latitude="{{center.latitude}}" longitude="{{center.longitude}}" scale="{{scale}}" bindmarkertap="onMarkerTap" />`,占满首屏(`.map { width: 100%; height: 70vh; }`),下面列一遍公园卡片(名字 + 在场数,点了同样进公园页)—— 模拟器里 `<map>` 不一定渲染,列表是兜底。
   - `onMarkerTap(e)`:`e.detail.markerId` → 找到 `parks[markerId]` → `navigateTo('/pages/park/park?parkId=...')`。
   - 不开 `show-location`(会触发定位授权);不接腾讯地图 SDK。
3. **公园详情 `pages/park`:**
   - `onLoad(query.parkId)` 没拿到 → `errMsg`;`loadBoard()`:`api.getParkBoard(parkId)` → `park` / `dogs` / `todayDogs` / `myCheckin`;`setNavigationBarTitle(park.name)`。`onShow`(非首次)与下拉刷新都重新拉 —— 从签到页回来要立刻看到自己的狗。
   - `emptyText`:`dogs` 为空时 `'这个公园还没有狗狗,签到成为第一只吧'`;`todayDogs` 为空时另一句。
   - 狗卡片只显示 DogCard 五个字段:头像(没有就 🐶 占位)、名字、`enums.SIZE_LABEL[sizeClass]`、`enums.labelsOfTags(tags)`。**不显示任何主人信息** —— 数据里本来就没有,测试里也别造。
   - 按钮:`myCheckin` 为 `null` → 「签到」`navigateTo('/pages/checkin/checkin?parkId=...')`;非 null → 显示「在场中,HH:mm 前有效」+「签退」→ `api.cancelCheckin(myCheckin.checkinId)` → 重拉。另放「在这发起约遛」→ `navigateTo('/pages/walk/create/create?parkId=...')`。
   - 时间格式化(ISO → `HH:mm`)放自己目录下的 `format.js`,纯函数。
4. **签到页 `pages/checkin`:**
   - `onLoad(query.parkId)` → `api.listMyDogs()`;只有一只狗时默认选中;没有狗 → 空状态「先去『我的』加一只」。
   - `submit()`:连点保护(`submitting`);没 `parkId` → `errMsg`;没选狗 → `errMsg`,**不调 api**;然后 `getLocation` → 失败 → `errMsg: '需要定位权限才能签到,请到设置里打开'` 并给一个「去设置」按钮调 `openSetting`,不调 `api.checkin`;成功 → `api.checkin({ parkId, dogIds, latitude, longitude })` → `showToast` + `navigateBack`。
   - 错误文案:`OUT_OF_RANGE` → `'你离公园还有 ' + e.message + ' 米,走近一点再签到'`(`e.message` 就是 fail 的 msg,即整数米数);`CONFLICT` → `'你已经在这个公园签到过了'`;`NOT_FOUND` / `FORBIDDEN` / `INVALID_PARAM` 各给一句人话;其他给 `e.message`。
   - 页面上写明「签到 2 小时内有效,坐标只用来校验、不会保存」。
5. **测试**(`jest.mock('../../miniprogram/api/index')`,`loadPage` 载页):
   - B8:`api.listParks.mockResolvedValue([两个 ParkSummary])` → `onLoad` 后 `data.markers.length === 2`,`markers[i].callout.content` 含 `activeDogCount`;`listParks` 先返回 `[]` 再返回列表 → `initParks` 被调恰好一次;`listParks` reject → `errMsg` 非空、不抛。
   - B9:未选狗 `submit` → `api.checkin` 未被调;`stubs.wx.getLocation = (o) => o.success({ latitude: 30.27, longitude: 120.15 })` → `api.checkin` 收到 `{ parkId, dogIds, latitude: 30.27, longitude: 120.15 }`;`api.checkin` reject `Object.assign(new Error('350'), { code: 'OUT_OF_RANGE' })` → `errMsg` 含 `350`;`getLocation` 走 `fail` → `errMsg` 含「定位」且 `api.checkin` 未被调。
   - park:`dogs: []` → `data.emptyText` 含「第一只」;`myCheckin` 非 null → 调 `onCancel` 后 `api.cancelCheckin` 收到那个 `checkinId`;`getParkBoard` reject → `errMsg`。
   - 页面 `data` 里不许出现 `openid` / `nickname` —— 写一条 `JSON.stringify(page.data)` 的断言。
6. 样式只用 `app.wxss` 的变量与类(`.card` / `.btn-primary` / `.btn-ghost` / `.empty` / `.banner-err` / `.chip` / `.avatar`),主色不要另定义。空状态、loading、errMsg 三件套每页都要有。
7. 跳 tab 页(`/pages/index/index`、`/pages/walk/list/list`、`/pages/me/me`)用 `switchTab`,其他用 `navigateTo`。
8. 后端(T7)与你并行,你的测试全靠 mock api,**不要**去 `cloudfunctions/` 里看实现来「对齐」—— 以 spec 3.2.3 的形状为准,T7 也按它写。
