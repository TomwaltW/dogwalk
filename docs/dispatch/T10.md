## 6. 实现要点

1. **`logic/compat.js`** 严格按 3.3.6:导出 `compatHints(myDogs, otherDogs)` 与 `RULES`。每条规则 `{ id, level, when(mine, other), text(mine, other) }`,`mine` / `other` 都是 `DogCard[]`;`compatHints` 遍历 `RULES`,`when` 为真就 push `{ level, text }`。至少五条初始规则(fearsBig-vs-large / size-gap / foodGuard / shy / chaser-vs-calm),文案点名狗的名字(`'豆豆怕大狗,而你的旺财是大型犬,先隔远一点熟悉'`)。纯函数,不 require 页面、不碰 wx;入参为空数组或缺 `tags` 时不抛、返回 `[]`。
2. **页面骨架**照 3.3.4:`wx` 一律 `host.wxOf(this)`;页面里不许 `new Date()` / `Math.random()` —— 需要「现在」(发起页的最早可选时间、列表的默认日期)时放 `pages/walk/clock.js`(同第一轮 `checkin/clock.js`),测试 `jest.mock` 掉。占位页里的 `void api; void host;` 删掉。每页 WXML 末尾保留 `<privacy-popup id="privacy-popup" />`。
3. **`walk/list`(tab 页):**
   - `onLoad`:`api.listParks()` 填公园筛选 picker(首项「全部公园」);`onShow` / 下拉刷新 / 筛选变化都 `loadWalks()` → `api.listWalks({ parkId?, date? })`(没选就不传那个 key)。
   - 行内容:公园名、时间(`MM-DD HH:mm`,自己目录下 `format.js`)、发起人的狗(名字 / 头像,只用 `hostDogs` 的 DogCard 字段)、`dogCount/maxDogs`、备注、我的关系(`myStatus` → `enums.MEMBER_STATUS_LABEL`,`host` 显示「我发起的」)。
   - 日期筛选:`<picker mode="date">`,清空按钮;空状态 `data.emptyText`「这天还没有人约遛,发起一个吧」;右下角悬浮「发起约遛」→ `navigateTo('/pages/walk/create/create')`。点行 → `navigateTo('/pages/walk/detail/detail?walkId=')`。
4. **`walk/create`:**
   - `onLoad(query.parkId)` 预选公园;`api.listParks()`、`api.listMyDogs()` 并行拉;狗只有一只时默认选中。
   - 表单:公园 picker、日期 picker + 时间 picker(合成 `startAt` 的 ISO,最早不能早于 `clock.nowIso()`)、带哪几只狗 chips、备注(≤ `LIMITS.WALK_NOTE_MAX`)、狗数上限(1-`LIMITS.WALK_MAX_DOGS_CAP`,默认 `LIMITS.WALK_MAX_DOGS_DEFAULT`,减到不能小于已选狗数)。
   - 本地拦截(不调 api):没选公园 / 没选狗 / 时间在过去 / 备注超长 / 选的狗数 > 上限,各给一句 `errMsg`。
   - `api.createWalk(payload)` → `redirectTo('/pages/walk/detail/detail?walkId=' + res.walkId)`。
5. **`walk/detail`:**
   - `onLoad(query.walkId)` → `api.getWalk(walkId)` → `data.walk` / `hostDogs` / `members` / `messages` / `myDogs` / `myStatus`;`onShow`(非首次)重拉。
   - 合拍度:`others` = `hostDogs` + `members` 里 `status:'approved'` 且 `!isMe` 的狗;`mine` = `myStatus === 'host'` ? `hostDogs` : `myDogs`;`data.compatHints = compat.compatHints(mine, others)`,页面上按 `level` 用 `.banner-warn` / 普通行显示。
   - 按 `myStatus` 分支:`none` → 「申请加入」:弹出选狗(从 `myDogs` 多选,没狗就提示去加)→ `api.joinWalk(walkId, dogIds)` → 重拉;`pending` → 「等待发起人确认」+「取消申请」(`leaveWalk`);`approved` → 留言区 +「退出」(`leaveWalk`,先 `showModal` 确认);`host` → 待确认成员列表每条「同意」/「婉拒」(`decideJoin(memberId, true/false)`,`WALK_FULL` 给人话「狗数已满,改上限得重新发起」)+ 留言区 +「取消约遛」(`cancelWalk`,先确认);`rejected` / `left` → 只读 + 一句提示。
   - 留言区:只在 `messages` 非空或 `myStatus ∈ {host, approved}` 时渲染;每条显示 `dogName` + 时间 + 文本,`isMe` 的靠右;输入框(≤ `LIMITS.MESSAGE_MAX`)+ 发送 → `api.postMessage` → 重拉。`walk.status === 'cancelled'` 时顶部横幅「已取消」,所有操作按钮隐藏。
   - 成员卡片只显示 DogCard 字段 + 状态文案,**没有主人昵称**。
6. **测试**(`jest.mock('../../miniprogram/api/index')`,`loadPage` 载页,`clock.js` mock 掉):
   - B13(compat):`compatHints([{ name:'旺财', sizeClass:'large', tags:[] }], [{ name:'豆豆', sizeClass:'small', tags:['fearsBig'] }])` 至少一条 `level:'warn'` 且 `text` 含 `豆豆`;两边都没标签且体型相同 → `[]`;`RULES` 是非空数组且每条有 `id` / `level` / `when` / `text`;空入参不抛。
