## 6. 实现要点

1. `expireAt = startAt + CHECKIN_DURATION_MS`,常量 `require('../_shared/contracts')` 取,**不要写 `90*60*1000` 字面量**(3.2)。B3 断言的就是这个差值。
2. **B8 的边界是反直觉的:`isActive()` 对恰好等于 `expireAt` 的时刻要返回 `false`**(2.2 B8)。写成 `now < expireAt`,不是 `<=`。
3. `spotBoard` 一个云函数两种返回形状:**无 `spotId` 返回数组**(点位摘要列表),**有 `spotId` 返回对象**(`{spot, sessions, wxGroupQrFileID}`)(3.3.2)。两条路径都要做,别只做一种。
4. 看板过滤要两个条件同时成立:`expireAt > now` **且** `status === 'active'`(2.2 B4)。无广播时返回**空数组**而不是报错。
5. CONFLICT 判定要四条同时成立:同一 `openid` + 同一 `spotId` + `status === 'active'` + 未过期,才 `fail(CODES.CONFLICT, 'active checkin exists')`(3.4)。
6. `notified` 的计数口径(3.4):订阅额度为 0 的用户**不报错**、只是不计入 `notified`;发订阅消息的 `ctx.openapi` 调用失败只记 `ctx.logger.error`,**主流程照常返回 ok**。测试里把 `ctx.openapi` 换成会 reject 的 mock,断言仍然 `ok:true`。
