## 6. 实现要点

1. **本地校验写在自己的 `pages/dog/dog-meta.js` 里**,枚举与上限从 `miniprogram/logic/enums.js` 取(`TAGS` / `TAG_LABEL` / `SIZE_LABEL` / `GENDER_LABEL` / `LIMITS` / `charLength`)。`logic/dog.js` 是 T6 的文件、正在被改,和它耦合你的测试会在合流时红。`page-host.js` 可以删了改用 `logic/host.js`(功能一样,多了 `promisify`)。占位页 `tag.js` 里那两行 `void api; void host;` 删掉。
2. **`dog/edit`:** 表单字段按 v2:名字(≤12 码位)、品种(≤20)、性别 picker、出生年月(`YYYY-MM` 或空)、体型 picker、已绝育 switch、疫苗齐全 switch(`vaccinated`)、犬证号(`licenseNo`,≤32,选填)、性格标签 chips(`TAGS` 多选)。删掉第一轮的玩法 / 性格两组 chips、`okWithSmallDogs` / `socialOk` 两个 switch,以及「狗牌」那块(搬到 tag 页),换成一个「身份牌」入口按钮(已保存的狗才显示)。
   - 照片:`chooseMedia({ count: 1, mediaType: ['image'], sizeType: ['compressed'] })` → `tempFiles[0].tempFilePath` → `api.uploadFile(cloudPath, tempFilePath)` → 写进 `data.dog.avatarFileID`,期间 `uploading:true`。`cloudPath` 要唯一但页面里不许 `Date.now()`:在 `pages/dog/clock.js` 放一个 `nowMs()`(同第一轮 `checkin/clock.js` 的做法),测试 `jest.mock` 掉。
   - 提交载荷只带 12 个可写字段(3.3.2),`_id` 决定 create / update。名字超长本地拦下不调 api(第 6 节)。`CONTENT_RISKY` 的人话:`'「' + 字段中文名 + '」含不合适的内容,改一下再保存'`。
3. **`dog/tag`(新):** `onLoad(query.dogId)` → `api.listMyDogs()` 找到这只狗;没 `qrFileID` → `api.genTag(dogId)` 补上(`genTag` 抛错 → `errMsg`,页面照常显示其他部分)。
   - 展示:小程序码大图(点开 `previewImage`)、`tagCode`、说明文案(「打印后挂在项圈上,路人扫码能看到档案并给你留言」)。
   - 「保存到相册」:`api.downloadFile(qrFileID)` → `saveImageToPhotosAlbum({ filePath })` → toast;`fail` 的 `errMsg` 含 `auth deny` / `authorize` 时提示去设置并给「去设置」按钮(`openSetting`)。
   - 「走失模式」switch:开 → 先 `requestSubscribeMessage({ tmplIds: [config.SUBSCRIBE_TEMPLATES.foundReport] })`(模板 id 还是占位符 `config.isPlaceholder(...)` 时**跳过这步**并在页面上提示「模板未配置,收不到通知」);结果里该 id 为 `'accept'` → `api.grantSubscribe('foundReport', 那个 id)`;**无论用户接不接受订阅**,接着都调 `api.setLostMode(dogId, true, lostNote)`。关 → `api.setLostMode(dogId, false)`。`lostNote` 是一个 ≤50 字的 textarea,走失态下可改,改完调 `setLostMode(dogId, true, 新 note)`。
   - 「寻回留言」列表:`api.listFoundReports(dogId)` → 时间(`YYYY-MM-DD HH:mm`,ISO 转换的纯函数放自己目录)+ 留言 + 有坐标时一个「看位置」→ `openLocation({ latitude, longitude })`。空状态「还没有人留言」。走失态下顶部提示「已开启走失模式,路人扫牌会看到你的留言」。
4. **`dog/profile`(寻回页,扫码落地):** `tagCode` 的两条来路保留(`query.scene` / `query.tagCode`)。`api.getDogPublic` → 只显示 DogPublic 的字段:头像、名字、品种、体型、性别、出生、标签;**页面 `data` 里不许有任何主人字段**(`ownerContact` / `canContact` / `onContactOwner` 全删)。
   - `data.showLostBanner = !!dog.lostMode`;走失态顶部醒目横幅「我走丢了,看到我请给主人留言」+ `lostNote`。
   - 留言表单(游客也能用,不跳登录):textarea(≤200)+ 「附上我的位置」checkbox + 提交。提交:空留言拦下;勾了位置 → `getLocation`,失败 → `errMsg` 提示但**仍可不带位置提交**(再点一次时 `attachLocation` 已被自动取消勾选);`api.reportFound({ tagCode, message, latitude?, longitude? })` → `data.sent = true`,显示「已通知主人」(`notified:false` 时显示「已留言,主人打开小程序就能看到」)。`CONTENT_RISKY` 给人话。
   - `onShareAppMessage` 保留,走失态标题「帮忙找找 X」。
5. **`me`:** 登录按钮逻辑保留(`api.login` → `globalData.user / logged`)。
   - 「我的狗」:头像 / 名字 / 体型 / 标签文案;每条两个入口:「编辑」→ `dog/edit?dogId=`、「身份牌」→ `dog/tag?dogId=`。空状态「还没有狗,先加一只」。
   - 「我发起的约遛」/「我参加的约遛」:`api.listWalks({ mine: true })` 一次拉回,按 `isHost` 分到 `data.hostedWalks` / `data.joinedWalks`(`myStatus` 显示成 `enums.MEMBER_STATUS_LABEL`,`status:'cancelled'` 标「已取消」);每条显示公园名 + 时间 + 狗数;点进 `walk/detail?walkId=`。两栏各自有空状态。
   - `onShow` 时重拉(从编辑页 / 身份牌页回来要看到最新)。`me` 是 tab 页,别人跳过来用 `switchTab`,你跳别人用 `navigateTo`。

   旧测试里第一轮字段(`playStyle` / `okWithSmallDogs` / `socialOk` / `ownerContact`)的用例全部换掉,不要留。
